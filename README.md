# HISTREE: Do You Know Your Institute?

Pop-up museum website for Team CakedUp (UPDH, IIIT Hyderabad, 14 November 2026).

- `context.md`: all facts, sources, conflicts, the exhibit structure and the physical build plan. Start here.
- `IMPLEMENTATION_PLAN.md`: how to build the website (for Claude Code agents).
- `raw/`: original files (interviews, photos, prospectus, floor plans, Ping article). Never edit these.
- `sources/`: readable text versions of the interviews and documents.
- `site/`: the website (to be built). Open `site/index.html` in Chrome; no internet or server needed.

This README gets replaced by Agent A during the build (see the plan, section 10).
